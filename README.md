🛡️ AI-Powered Network Security Monitor

Real-time Traffic Analysis & Threat Detection Dashboard

This project is a high-fidelity web application that simulates a professional network security monitoring tool. It demonstrates the ability to handle high-frequency data streams, implement real-time anomaly detection logic, and visualize complex network metrics for security operations centers (SOC).

✨ Key Features & Technical Highlights

This dashboard is a powerhouse for showcasing infrastructure and security-focused development skills:

Feature

Technical Skill Demonstrated

Real-time Packet Simulation

Orchestrating a continuous stream of simulated "Network Packets" with varying metadata (IP, Protocol, Payload Size).

Heuristic Anomaly Detection

Implementation of logic to identify Security Threats (e.g., Port Scans, DDoS, Brute Force) based on packet frequency and origin patterns.

Live Throughput Visualization

High-performance rendering of time-series data using Chart.js, showing incoming vs. outgoing traffic in real-time.

Global Traffic Mapping

Using an interactive SVG-based map to visualize the geographical origin of simulated network requests.

System Event Logging

A high-speed, filterable log system that categorizes events by severity (INFO, WARN, CRITICAL).

AI Insights (Simulated)

A dedicated panel that provides automated "Security Recommendations" based on current traffic trends.

🛠️ Technology Stack

Frontend: HTML5, Vanilla JavaScript (ES6+)

Styling: Tailwind CSS (for an enterprise-grade dark-mode UI)

Visualization: Chart.js (Throughput monitoring)

Icons: Lucide Icons (via CDN)

🚀 How to Run the Monitor

This project is a self-contained simulation designed to run instantly in any modern browser.

Open the file: Load network_security_monitor/index.html in your browser.

Start Monitoring: Click the "Initialize Monitor" button. The packet stream will begin immediately.

Monitor Threats: Watch the Threat Detection panel for real-time alerts as the system identifies suspicious traffic spikes or patterns.

Analyze Trends: Review the Throughput Chart to see how bandwidth fluctuates based on current network activity.

Adjust Sensitivity: (Planned feature) You can modify the "Anomaly Thresholds" to see how it affects threat detection accuracy.
